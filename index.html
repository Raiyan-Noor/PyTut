The Concept, Properly Explained

What Actually Is an API?

API stands for Application Programming Interface. Forget the words for a second and think of it like this instead:

An API is a set of rules that lets one piece of software ask another piece of software for something, and get an answer back - without needing to know how that other software works on the inside. You just need to know what to ask for, and how to ask.

Here's the same idea, in places you've used a hundred times without realising it was an API:

🌬
Weather App
Your phone doesn't know the weather itself - it asks a weather service's API and gets data back.
🗺
Maps App
When you search a place, your app asks a maps API "where is this?" and gets back coordinates, a route.
🍕
Food Delivery
The app asks a restaurant's API "what's on the menu, is it open?" and displays whatever comes back.
🎮
Game Leaderboard
Your score gets sent to an API, which stores it and sends back everyone else's scores.

Notice the pattern in every one: you ask for something specific, and you get a specific answer back. That's genuinely the whole idea.

You've actually used an API before - Ollama. ollama.chat() was you asking a program (running locally) a question and getting an answer. Today's different only in where that program lives - not your laptop, but a company's servers.
The Important Part

What Is an API Key?

Ollama never needed a key, because it ran on your own computer - nobody else could use it but you. A cloud API is different: it's a shared service thousands of people use, running on someone else's servers. The company needs to know who is asking.

Why Keys Exist

An API key is like a personal password that identifies you to the service. It lets the company track which requests are yours, how much you've used, and stop random strangers using their AI for free on your account.

The Rules — Take These Seriously

  • Never share your key with anyone - not in Discord, not in a screenshot, nowhere public
  • Never post code containing your key - blank it out before sharing anything
  • If you think it leaked, tell Raiyan immediately - keys can be replaced, but only if someone knows to do it
Why this matters: if someone else gets your key, they can use it to make requests that might cost real money, on your account. Treat your key exactly like a bank password.
Practical tip: put your key in a variable right at the top of your file, and never paste that file anywhere public.

New Skill

What Is JSON, Properly?

You've actually been looking at JSON this whole time without it being named properly. Time to make it official.

JSON stands for JavaScript Object Notation - but despite the name, it's used by almost every programming language now, not just JavaScript. It's the standard way computers send structured data to each other over the internet.

Every single API you've used sends its data as JSON - the Trivia API, Ollama, and OpenRouter. Here's a plain example of what it looks like:

example.json
{ "name": "Aariz", "age": 10, "hobbies": ["piano", "football", "basketball"] }
Look familiar? That's because JSON's shape is basically identical to a Python dictionary - curly braces, keys in quotes, values that can be strings, numbers, or even lists. That's not a coincidence. Python's json module exists specifically to convert between the two.

Here's the key idea for today: since JSON is just structured data, you can ask an AI to give you its answer as JSON instead of a normal sentence - which means your program can actually use the answer, not just display it.

The Real Skill

Making an AI Return JSON

Normally, an AI replies with a normal, chatty sentence. But if you tell it exactly what format you want and exactly which fields to include, it'll usually follow along.

the instruction
{"role": "system", "content": "You are an event extractor. Given a description of an event, respond with ONLY a JSON object with these exact keys: event_name, date, time, location. Do not include any text outside the JSON object."}

Now if you send it something like "Aariz's birthday party is this Saturday at 4pm at Funland arcade", it should reply with something like:

what comes back
{"event_name": "Aariz's birthday party", "date": "Saturday", "time": "4pm", "location": "Funland arcade"}
Here's the catch: even though that reply LOOKS like JSON, Python doesn't know that automatically. The AI's answer comes back as a plain string of text. You need to explicitly convert it into a real dictionary using json.loads().
parsing it
import json reply_text = data["choices"][0]["message"]["content"] event_data = json.loads(reply_text) print(event_data["date"]) print(event_data["location"])
Notice json.loads() is new - not the same as json.load() from file storage. The one with an "s" (loads = "load string") converts a JSON-shaped string of text into a real dictionary. You'll use this exact function again and again once you're pulling structured answers out of AI replies.
If json.loads() ever crashes with an error, it's almost always because the model added extra words around the JSON, like a code fence or a sentence before it. The fix: make your instruction even more explicit - "respond with ONLY the JSON object and nothing else."

New Topic

Functions

Afraz - today's about functions. A function is a named block of code that you can run any time just by saying its name, instead of retyping the same lines over and over.

You've actually already used functions loads of times without building your own - print(), input(), len() are all functions. Today you write your own.

The Basic Shape

example.py
def greet(): print("Yo what's good") greet() greet()

def means "I'm defining a function." greet is the name - you could call it anything. Everything indented underneath is what runs each time you call it.

Giving It Information — Parameters

example.py
def greet(name): print("Yo " + name + ", what's good") greet("Afraz") greet("Aariz")

name inside the brackets is a parameter - a variable that gets filled in differently each time you call the function.

Getting Something Back — Return

example.py
def double(number): return number * 2 result = double(5) print(result) # prints 10
If you forget return, your function won't crash - it'll just quietly give you back None instead of a real answer.

Problem 3 of 6

Functions + Conditionals

3
Practice Tracker

Write a function called check_practice that takes minutes practised as a parameter, and returns a different message depending on how long: 30+ minutes returns "Great session!", 10-29 minutes returns "Decent effort.", under 10 minutes returns "Try a bit longer next time."

check_practice(45) → "Great session!"
check_practice(15) → "Decent effort."
check_practice(5) → "Try a bit longer next time."
The conditional goes right inside the function body:

def check_practice(minutes):
    if minutes >= 30:
        return "Great session!"
    elif minutes >= 10:
        return "Decent effort."
    else:
        return "Try a bit longer next time."
The function decides which message fits, and hands back exactly one clean answer.
Problem 4 of 6

Functions With Multiple Parameters

4
Average Practice Score

Write a function called average_score that takes three numbers as parameters - three separate practice session scores - and returns their average.

average_score(8, 9, 7) → 8.0
A function can take more than one parameter - just separate them with commas in both the definition and the call:

def average_score(a, b, c):
    return (a + b + c) / 3
This is the first function you've written with more than one parameter - notice the order you pass values in matches the order of the parameter names.
Problem 5 of 6

A Loop Inside a Function

5
Race Start Countdown

Write a function called print_countdown that takes a starting number as a parameter, and uses a loop to print every number counting down from that number to 1, then prints "Go!" at the end.

print_countdown(3) → prints 3, 2, 1, Go!
Everything you know about for loops still works exactly the same inside a function:

def print_countdown(start):
    for i in range(start, 0, -1):
        print(i)
    print("Go!")
A function can contain a loop, an if statement, another function call - anything you already know how to write goes inside just as normal.
Problem 6 of 6

A Function Calling a Function

6
Bonus Round, Take Two

Write a function called bonus_round that takes a score, calls your earlier double_points function on it, then adds a fixed bonus of 5 points on top, and returns the final total.

bonus_round(10) → double_points(10) is 20, plus 5 bonus = 25
Functions can call other functions you've already written - just use it like any other value:

def bonus_round(score):
    doubled = double_points(score)
    return doubled + 5

Make sure double_points is defined somewhere above this in your file.
This is a genuinely important idea - functions don't have to work alone. Once you've built one, other functions can reuse it instead of rewriting the same logic again.
