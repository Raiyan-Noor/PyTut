New knowledge

Reading the clock on your device

One of your functions needs to know what time it is right now, and calculate how many hours are left until midnight. Python has a built-in way to check the device clock.

import datetime now = datetime.datetime.now() print(now.hour) # current hour, 0 to 23 print(now.minute) # current minute, 0 to 59

That's it. datetime.datetime.now() grabs the current time from your computer. .hour and .minute pull out the two numbers you need.

Turning hour + minute into "time left"

Here's the maths, step by step:

# step 1: how many minutes have passed since midnight? minutes_passed = now.hour * 60 + now.minute # step 2: how many minutes are left until midnight? minutes_left = (24 * 60) - minutes_passed # step 3: convert minutes_left into hours + minutes hours_left = minutes_left // 60 mins_left = minutes_left % 60

Two new symbols

// — floor division. Normal division but it throws away the decimal. 130 // 60 gives 2 (2 whole hours, ignoring the remainder).

% — modulo. Gives you the leftover after dividing. 130 % 60 gives 10 (10 minutes left over after those 2 hours).

Together, // and % split any number of minutes into clean hours + minutes. This trick works anywhere you need to convert a big number into two friendlier ones — you'll use it again later.
New knowledge

Changing a list from inside a function

You'll write two functions that add and remove habits from a list. Here's something that'll feel a little different from what you're used to.

habits = ["Piano", "Football"] def add_one(the_list, item): the_list.append(item) # notice: no return! add_one(habits, "Basketball") print(habits) # ['Piano', 'Football', 'Basketball']

Even though add_one never returns anything, the original habits list still changed. That's because lists are mutable — when you pass a list into a function, the function is working on the exact same list, not a copy. Anything you do to it inside the function sticks, even without return.

This is different from things like numbers, which get copied when passed into a function. Lists (and later, dictionaries) are handed over directly — changes inside the function are permanent.
⚠️ One thing to watch for with removing: if you try to .remove() something that isn't in the list, Python will crash. Always check if item in the_list: before removing it.
