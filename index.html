Maths & variables

Variables are boxes that hold stuff. Numbers go in without quotes. You can do maths on them directly.

# variables hold values aura_points = 100 wins = 3 Ls = 1 # maths — just like a calculator total = (wins * 100) - (Ls * 75) print("Aura score: " + str(total))

Remember: when you want to print a number inside a sentence you have to wrap it in str() — otherwise Python gets confused and crashes.

if / elif / else

Conditionals let Python make decisions. Think of it as Python asking itself "is this true? if yes, do this. if not, do that."

aura = 250 if aura >= 300: print("Sigma. Built different.") elif aura >= 100: print("Du bist gut genug. Keep going.") else: print("Mid era ngl.")

With aura = 250, which line prints?

Remember: the colon at the end of if and the indent (tab key) before the code inside it — both are required. Python will crash without them.

New skill

Meet .replace()

Here's the one new thing you're learning today. It's called .replace() and it's a string method — meaning it's something you can do to a string.

How it works

sentence = "I had a good day" result = sentence.replace("good", "bussin") print(result) # prints: I had a bussin day

You give it two things: the word to find, and the word to swap it with. Python finds every single one of that word in the string and swaps them all.

You can chain them together

This is the real trick. You can do multiple replacements one after another on the same line — or line by line:

sentence = "That was bad and weird ngl" result = sentence result = result.replace("bad", "mid") result = result.replace("weird", "Ohio") print(result) # prints: That was mid and Ohio ngl

Level 1 — basic translator

Open Thonny. Create a new file called translator.py. Type this out — don't copy paste.

# The Brainrot Translator — Level 1 # by Aariz / Afraz sentence = input("Type a sentence: ") result = sentence result = result.replace("good", "bussin") result = result.replace("bad", "mid") result = result.replace("crazy", "cooked") result = result.replace("cool", "rizz") result = result.replace("weird", "Ohio") print("Brainrot version: " + result)
